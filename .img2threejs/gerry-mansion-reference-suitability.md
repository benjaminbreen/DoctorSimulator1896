# Reference suitability: pass

The reference passes for an approximate real-time procedural reconstruction.

- It contains one unambiguous architectural target on a neutral background.
- The full building silhouette and both street-facing elevations are visible.
- The pavilion, wings, roofs, dormers, chimneys, loggia, conservatory, and primary materials are legible.
- The geometry is dominated by cuboids, shared hip/gable profiles, arches, and instanced trim that fit the existing game renderer.
- The hidden rear can be inferred conservatively because the requested fidelity is for the playable street views, not survey-grade reconstruction.

Limits: rear massing, exact dimensions, and hidden conservatory construction are undetermined. The result will be an explicitly approximate low-poly interpretation, not an exact extracted mesh.
