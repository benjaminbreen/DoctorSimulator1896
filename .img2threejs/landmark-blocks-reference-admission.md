# Reference admission

The overhead capture is admitted as ground truth only for map placement,
negative-space closure, block adjacency, and the current authored Metropolitan
Club anchor. It is explicitly not admitted as facade-detail ground truth.

The Vanderbilt and Gerry period photographs are admitted for visible
silhouette, material families, bay rhythm, and roof/entrance hierarchy. The
near-contemporary hotel and row-house records are admitted for relative height,
style, and street-wall composition. Because the implementation is a game-scale
ensemble, no source is treated as measured architectural documentation.
