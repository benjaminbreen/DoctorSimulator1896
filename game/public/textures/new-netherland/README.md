These three generated facade textures were supplied by the project owner for
the New Netherland Hotel reconstruction.

- `brick.webp`: red brick upper facade, resized to 1024px for runtime use
- `rusticated-stone.webp`: brownstone podium, resized to 1024px for runtime use
- `slate-shingles.webp`: slate roof and turret cap, resized to 1024px for runtime use

They are used as repeating color and restrained bump maps. The Phase 2 model
adds geometry for the primary courses, arches, cornices and entrance, so the
textures supply surface variation rather than the building silhouette.
