# Renderer C menswear source assets

## Toigo male suit, tie, and jacket

The `toigo_male_suit_tie_and_jacket` directory comes from the MakeHuman
Community `suits01` asset pack. Margaret Toigo created the asset and released
it under CC0. The original pack is available from:

https://static.makehumancommunity.org/assets/assetpacks/suits01.html

Renderer C uses this mesh as an MPFB-fitted deformation carrier for the
`mens-victorian-sample` proof of concept. The source mesh is a modern suit,
not an approved historical reconstruction. Runtime silhouette and material
changes make the trial closer to late nineteenth-century menswear, but Ben
must approve the historical design before it becomes game content.

## Additional Suits 01 candidates

The following CC0 Margaret Toigo assets come from the same official pack:

- `toigo_male_double-breasted_suit`
- `toigo_suit_with_dinner_jacket`

They retain their OBJ, MHCLO fit map, materials, textures and thumbnails. They
are deformation and construction candidates, not approved 1896 costumes.
