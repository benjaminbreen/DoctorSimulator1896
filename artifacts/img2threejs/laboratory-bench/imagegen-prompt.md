# ImageGen prompt

Use case: stylized-concept

Asset type: seamless tileable game texture, diffuse albedo source for a
real-time Three.js laboratory bench

Primary request: create a square seamless flat-lit albedo texture of scrubbed
pale deal softwood suitable for an 1890s laboratory work bench

Subject: close orthographic surface view of pale yellow-tan softwood boards;
long subtle grain fibers, fine pores, faint irregular growth lines, restrained
scuffing and scrub wear, a few very subtle desaturated reagent and ink
discolorations distributed without a focal point

Style/medium: realistic PBR material authoring source, diffuse/base-color only

Lighting: perfectly even neutral illumination; de-lit appearance; no
directional light

Color palette: warm pale straw, muted honey beige, slightly darker taupe grain;
low contrast

Composition: surface fills the full square canvas; seamless on all four edges;
grain generally runs horizontally; uniform texel density

Constraints: truly tileable edges; no perspective; no board border; no obvious
repeated knot; no deep cracks; no nail heads; no labels; no text; no logos; no
watermark; no shadows; no highlights; no ambient occlusion; no normal-map
colors; no baked lighting; no vignette

Avoid: furniture photograph, planks seen in perspective, dramatic stains,
strong knots, glossy varnish, orange saturation, directional shadows, visible
seams at image edges
